## Works today

- The shell (the terminal UI), the local gateway, durable sessions and profiles.
- One-line install on the three platforms above. See [Install](install.mdx).
- Automatic updates on installed builds. See [Updates](updates.mdx).
- Four provider wire formats: `openai-completions`, `openai-responses`, `anthropic`, `google`. See [Models](models.mdx).
- A nodecode.ai account: `nodecode login` signs in in a browser, and the footer shows the plan's requests left. See [First run](first-run.mdx#a-nodecodeai-account).
- Backup models: `/models` has a Backup tab, the models a failing turn moves on to. See [Models](models.mdx).
- Bots in Discord, Telegram and Slack, from cells that ship with Nodecode. See [Channels](channels.mdx).
- Cells, Nodecode's and the community's, listed under <CellsTab />. See [Cells](cells.mdx).
- `/doctor` health check and `/backup` home archive. See [Troubleshooting](troubleshooting.mdx).

## Windows limits

| Limit | Effect |
| --- | --- |
| No background gateway | `nodecode gateway on` is refused. Run `nodecode serve` in a terminal you keep open. |
| No gateway for cells | Cron, link, channels and prs run only while a shell or `nodecode serve` is open. |
| The terminal y/N prompt is not read | `nodecode add` for hub code and `nodecode profile delete` need `--yes`. |
| No profile wrapper command | `nodecode profile create` writes no `NAME` command. Use `nodecode -p NAME`. |
| No symlinks for shared folders | A new profile copies memory, skills and credentials. |
| `/chrome`'s onboarding has no opener | It cannot start Chrome. |
| No local speech or transcription engine | Downloads exist for Linux and macOS only. |
| `/doctor` shows no disk fact | The check uses `df`. |

## Safety limits

- `eval` has full host authority.
- The guard cell is not a security boundary. It refuses listed patterns.
- A cell folder is code with full access to your files and keys.
- Channel messages run with full host authority. Allowlists decide who may send them.
- Nodecode ships no sandbox. The organism is as isolated as the account it runs under.

Detail: [Security](security.mdx).

## Unfinished

| Area | State |
| --- | --- |
| Cell hub | The index is `https://nodecode.ai/dl/cells/index.json`; the community's is `https://nodecode.ai/cells/community.json`. `NODECODE_HUB_INDEX` and `NODECODE_COMMUNITY_INDEX` name others. |
| Update rollback | Not automatic. A build that fails to serve after a restart stays linked. See [Updates](updates.mdx). |
| Schema rollback | Rolling back after a store migration is manual. Copy the store first. |
| `profile switch` | Refused in a build that was not started from an installed binary. |
| `--ephemeral` | Channel adapters refuse to start. Definitions still go to the real layer. |
| `session_token`, `access_key_id`, `secret_access_key` | Only mark a provider as having credentials. No request sends them. |
| MCP | No `cwd`, no `${VAR}` expansion, no per-tool allow or deny, no OAuth. |
| `team` cell | Uses `/bin/sh` and `flock`. macOS and Windows are unverified. |
| `qa` cell | Sends nothing unless `share` is `weekly`. |
| `link` cell | Depends on an external relay, `wss://uplink.nodecode.ai/line` by default. |
