## Headless

A headless command answers without the shell, the terminal UI.

| Surface | How |
| --- | --- |
| Web page | Type the command in the page's composer, by its name. An alias, or a command with no headless arm, goes to the model. |
| Chat room | Send the command as a message. |
| Eval | `(slash "/think high")` |

In a chat room or eval, a shell-only command answers `/name needs an interactive shell`.

## Built-in

| Command | Does | Headless |
| --- | --- | --- |
| `/help` | Shows commands and key bindings. | Yes |
| `/clear`, `/new` | Starts a fresh session. Headless: moves this session back to its start. | Yes |
| `/sessions`, `/agents` | Opens the session picker. | No |
| `/rename [name \| default]` | Names the session, 64 characters at most. Bare: shows the name. | Yes |
| `/export [path]` | Saves the session as Markdown. | No |
| `/execs` | Shows an exec's output. Ctrl+X or Delete interrupts it. | No |
| `/tree`, `/checkpoints` | Opens the session tree. Continue from a turn, or rewind. | No |
| `/undo` | Rewinds the last turn. | Yes |
| `/redo` | Returns to the branch the last rewind left. | Yes |
| `/fork` | Forks a new session at the current head. | No |
| `/history` | Picks a past prompt into the composer. | No |
| `/themes [name]` | Lists themes, or switches to one. | No |
| `/settings` | Browses and changes settings. | No |
| `/models [provider] [model] \| aux [provider] [model \| default] \| decider [id \| none] \| list \| refresh` | Shows or changes the main, auxiliary and decider models. Bare: opens the picker. | Yes |
| `/evict [percent \| through TURN]`, `/compact` | Drops the oldest turns from the provider context: a percent of retained history, 1 to 100, default 50, or every retained turn through TURN. | Yes |
| `/context [prompt \| tools \| index \| notes \| history \| time]` | Shows this session's context window and usage. A part opens to what it holds. | Yes |
| `/status` | Nodecode right now: attention, runtime, services and today's usage. | Yes |
| `/usage [today \| 7d \| 30d \| all]` | Reports spend across sessions. Default: 7 days. Signed in to nodecode.ai, the shell shows the account first: the plan's requests left and the API credit. | Yes |
| `/login [subscription \| api]` | Signs in to your nodecode.ai account: a subscription or API credits. Bare asks which one. Same as `nodecode login`. | No |
| `/details developer\|standard` | Sets the Developer or Standard viewport, the mode Ctrl+O switches. Bare: reports it. | No |
| `/cells` | Every cell: turn one on or off, see why one failed. Headless: this process's cell report. | Yes |
| `/generations [N]` | The history of this organism, and the way back to a change in it. | Yes |
| `/doctor` | Lists what is missing, with the remedy. | Yes |
| `/backup` | Archives the home under `~/.nodecode/backups/`. The archive holds your keys. The web page's Settings pane lists, downloads and restores them. | Yes |
| `/profile [switch \| list \| use \| create \| delete \| export \| import \| install \| update \| help]`, `/profiles` | Manages profiles. Bare: opens the roster. | Yes |
| `/gateway [on \| off \| restart \| logs \| help]` | Same as `nodecode gateway`. | No |
| `/web` | Same as `nodecode web`. | No |
| `/setup` | Opens the setup walk. Takes no arguments. | No |
| `/think [rung]`, `/effort` | Sets reasoning effort. `default` uses the model's own. | Yes |
| `/gc [reset]` | Shows garbage collection and stall stats. `reset` restarts the window. | Yes |
| `/exit`, `/quit` | Exits the shell. | No |
| `/index [reload \| TEXT]` | Knowledge: the meter and the picker. `reload` re-pins; a text finds hot and cold. `$` at the start of a word opens it. | Yes |
| `/import [WORLD] [--source PATH] [--only KINDS] [--dry-run] [--overwrite] [--keep-running] [--yes]` | Brings another coding agent's home into this one: a preview first, `--yes` applies. `/import --sources` lists the repositories held, `/import --remove LABEL` takes one back. | Yes |

The gateway registers `/index` itself as it serves. It is no cell's.

| Command | Shell and headless differ |
| --- | --- |
| `/clear` | Shell: opens a new session. Headless: rewinds this session to its start. `/redo` returns. |
| `/undo` | Shell: restores files too. Headless: moves the conversation only. |
| `/models` | Shell: bare opens a picker with Main, Auxiliary, Decider and Backup tabs. A new provider is connected there; Ctrl+E replaces a key. Backup is the failover chain: `/models backups` opens on it. Headless: bare prints the current target. |
| `/generations` | Shell: a sheet of the changes; Enter asks in place, then restores. Headless: one card of the changes to page and pick from. `/generations N` asks first; `/generations N go` restores, or `keep` / `discard` when uncommitted edits hold it. |
| `/context` | Shell: a grid, each part opening to what it holds. Chat room: one card that wears the window's state, from fine to past the eviction line. |
| `/login` | Shell only. No chat room or web page can sign this home in to an account. |

Details: [Sessions and undo](sessions.mdx), [Models and providers](models.mdx), [Context](context.mdx), [Profiles](profiles.mdx), [Gateway](gateway.mdx).

## Cell

A cell is a folder of code under `~/.nodecode/cells/`. Its command exists while the cell runs. Every cell command is headless.

A built-in wins over a cell command of the same name.

A cell adds its own commands with the `:command` clause. See [Cell API](cell-api.mdx#define-cell). The cells you can add are listed under <CellsTab />.
