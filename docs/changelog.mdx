## Stable today

Linux x86_64, Windows x86_64 and macOS Apple Silicon run the same release: the newest one below. The installer and the updater read it from a pointer at `https://nodecode.ai/dl/`, one for each platform, and the pointer names the build it serves:

```sh
curl -fsSL https://nodecode.ai/dl/stable-x86_64-linux
```

```output
2629050e1
```

The other two are `stable-x86_64-windows` and `stable-arm64-darwin`. Every release is also a version on [GitHub's releases page](https://github.com/nodecode-ai/nodecode/releases), with its commits listed.

{/* source: nodecode.asd */}
## Your build

```sh
nodecode --version
```

```output
nodecode 0.1.7+2629050e1
```

The version comes first and the build label, the commit the release was built from, follows the `+`. An installed build moves to a new release by itself, between turns. `nodecode update` moves it now. See [Updates](updates.mdx).

## 0.1.14

Linux, macOS and Windows. Changes since 0.1.13 (`98dd6dc80`).

- `/models` lists Anthropic's models from Anthropic's own Models API, so a model it ships today is offered before any catalog carries it.
- `/models` finds a running Ollama with no config entry and lists its models under Local.
- A provider's `models[]` entry can declare its effort ladder with `reasoning_options`, for a gateway that refuses a thinking budget.
- Web search can use DeepSeek's own search, with a DeepSeek key.
- `@` finds workspace files by fuzzy match, and offers files written during the session.
- The draft marks text with Shift and the arrows, Home or End (Ctrl for words), or a drag. Typing or pasting replaces the mark, and it copies.
- A drag over your own prompt selects and copies it. A click still opens the session tree.
- A written file holding a Rust closure such as `spawn(|| 1)` no longer freezes the screen.
- After a model or effort change, the footer no longer stays on `setting up…`.
- An account with no plan or credit to meter reads Unlimited ∞ in the footer, `/usage` and at sign-in.
- A kept variable holding a process, thread, socket or open stream keeps its name alone, so a boot no longer starts that process again.
- A snippet can no longer delete or rename a package nodecode runs on. That took down every session until a restart.
- A home with many generations boots faster: the boot line reads the newest one first.
- `config-set` and `config-get` refuse a dotted name such as `"goal.check_seconds"`, which nothing reads. `/doctor` and the cell start name such a member and the nesting it meant.
- `restart-cells` takes the name `/cells` shows and says when a cell is off. A bare `restart-cells` starts no cell `/cells` turned off.
- A channel card whose picture Discord refuses to upload still updates its words.
- `nck:answer-file` refuses a file too large for the answer, so the turn can post it on its own.

## 0.1.13

Linux, macOS and Windows. Changes since 0.1.12 (`e105154bc`).

- On a Mac whose Homebrew `openssl` has moved to 4.x, sign-in, the provider list and updates work again: nodecode opens OpenSSL 3 by `openssl@3`'s own path, and reads a certificate through the name OpenSSL 4 kept. A Mac on 0.1.11 or 0.1.12 that met this cannot update itself, because its HTTPS fails: run the installer again, and it asks for `brew install openssl@3` when that is missing.
- `nodecode logout` and `/logout` also sign the machine out on nodecode.ai, so its key stops working.
- The footer shows nodecode.ai credit only while a session runs on nodecode.ai. `/account` and `/usage` still show it on any provider.
- A variable kept from a call keeps the value the call gave, so a later shell or boot no longer runs the call again: a kept post is posted once.
- An answer no message asked for no longer leaves an empty user message behind, which strict providers such as Kimi refused.
- A gateway restart keeps the jobs a tool shell left running.
- A picture in Konsole stays in its band.

- A sign-in in one shell updates the credit line in every shell.

## 0.1.8

Linux, macOS and Windows. Changes since 0.1.7 (`2629050e1`).

- Anthropic: a session whose history holds a tool result twice, or one that landed after a later message, no longer fails every turn with a 400. A repaired call id never reuses one already stored.
- A stream that stops sending content is cut after three idle timeouts, however many keep-alives still arrive, and an attempt that sends no content at all is cut after fifteen. Either goes to the next attempt or the backup model.
- A model that loops is cut and run again, never taken as its answer.
- A full `/tmp` no longer fails every turn, and a write that fails names its file.
- An image past 2000 px a side, or past a provider's 5 MiB, is shrunk to fit before it is sent. A JPEG shrinks through ImageMagick, ffmpeg or sips when the machine has one, and otherwise goes as it is when the provider takes it whole.
- The settings sheet, the cells sheet and `/generations` keep one layout at every width: a narrow window gets a slimmer rail beside the pane. `/tree` no longer marks cron fires, re-asks or steers, and the home mark's Konami code is gone.
- A turn can ask you a question at the web page or the desktop app and wait for your pick.
- The web page has a Board of tasks: To do, Running, Needs you and Done. Ctrl+K opens a command palette and Ctrl+P quick open. Settings > Shortcuts rebinds any key.
- The Files view edits and saves a text file, in syntax colours, and asks first over a file changed on disk. The message box records voice.
- A session's page steers or stops its helpers, one by one or all at once. A helper you steer answers with what the steer asked.
- The guard asks Allow once or Deny before it refuses a call, and the page draws the question.
- MCP: a remote server signs in with OAuth. The MCP tab is one line a server, its tools folded out, with a find across them.
- MCP: a server whose command signs in on its own, such as `npx mcp-remote URL`, fails in seconds and names the sign-in instead of waiting out its deadline. `(mcp:login NAME ADDRESS)` hands it a browser's landing address from another machine.
- The cron cell wakes a session on its own when something outside changes, such as a red CI run or an answer waiting.
- `/cells new`, or New cell in the Cells tab, makes a cell by talking.
- `nodecode gateway setup` opens the shell on a step-by-step setup sheet. Discord sets up from the bot token alone, and `/channels` picks its channels, people and roles.
- `nodecode --model M -- PROMPT` opens a fresh shell on that model with a first prompt; `--prompt-file FILE`, `@FILE` and piped stdin give it the prompt too. `nodecode web --print` prints the page's link and opens nothing.
- Ctrl+Y selects transcript text from the keyboard. Behind tmux or screen the pane keeps its title, and the cursor no longer flickers while the screen paints. A long session opens faster.
- `edit` and `write-file` keep a file's mode. A backgrounded or stopped `(sh ...)` answers what its command wrote, and a command's output that is not UTF-8 reads as `?` instead of failing. An eval runs on its turn's model.
- `nodecode add` says what it waits on, and names it when it gives up.
- A profile made from your settings carries the cells the hub installed and the folder a pinned provider needs. A models.dev address with a `${NAME}` blank asks for the value.
- An update moves a definition that moved to another file, and an install removes the older releases nothing uses.

## 8490b4803

Linux and Windows, 2026-10-06. Changes since `dc14c36f5`.

- Add-ons are now cells. `~/.nodecode/addons/` is `~/.nodecode/cells/`, and `/addons` is `/cells`. This build does not read an `addons/` folder an earlier release left.
- The shell starts the organism as its own `nodecode serve` process. Keys, the screen and Esc stay quick while an eval keeps it busy, and Esc says `stopping…` at once.
- A relaunch after a quit, or after `pkill nodecode`, connects in under a second.
- A `/think` pick is the effort every new session starts at, as a `/models` pick is its model. A session's own pick outranks it.
- On the `openai-responses` dialect, every reasoning item of an answer is kept and sent back in order, not only the last.
- A boot hands the layer files it could not load to the model, in a session named `layer`. An update removes installed cells the new build no longer ships.
- Windows: `nodecode` runs in an elevated shell after an update.
- Telegram: answers render as Markdown. A turn's card is a rich message, its steps a checklist, with Stop and Details inside it.

Earlier releases are not listed.
