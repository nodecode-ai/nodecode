Nodecode is built from cells. Discord, Telegram, cron, the guard: each is a folder you can see in `/cells` and switch off. Ask for a part it does not have, and the agent writes one and loads it into the running process.

<Recording name="cells" />

Asked for a `/owed` command that lists who owes money, it:

1. Makes a cell of its own: the folder `mike-owed`, with its own git repository.
2. Writes the command: a function that reads the ledger, with two small helpers.
3. Loads the cell and runs the command once, before it says it works.

`/owed` answers at once, and `/cells` lists the new cell under Your own, running. The session never stopped.

## How

- Say what it should do: "Make a cell with a `/tokyo-time` command that says the time in Tokyo." The agent asks only what it cannot work out, such as an API key.
- `/cells` lists every cell. Space switches one off and keeps its folder.
- A cell is a git repository. Push it anywhere to share it.
- More cells, Nodecode's and the community's, are under <CellsTab />. `nodecode add nc://NAME` installs one.

Every rule and table: [Cells reference](cells-reference.mdx). How a cell is written: [Cell API](cell-api.mdx).
