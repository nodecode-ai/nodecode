Nodecode is built from cells. Discord, Telegram, cron, the guard: each is a folder you can see in `/cells` and switch off. More are on the hub, and one line adds one.

<Recording name="cells" />

`nodecode add nc://lsp` adds [nodecode-lsp](https://github.com/nodecode-ai/cells/tree/main/tools/nodecode-lsp), a port of [oh-my-pi](https://github.com/can1357/oh-my-pi)'s language-server module:

1. Before installing, it shows the repository, the commit it is pinned at, and that the cell runs with full access to your files and keys.
2. Pyright is on the PATH, so the cell starts it the first time the agent writes a Python file.
3. The agent's edit multiplies a `Decimal` by a `float`. The eval that wrote the file comes back with pyright's error at `app/invoices.py:28:16`: Operator "\*" not supported for types "Decimal" and "float".
4. The agent fixes it before a test runs. `/cells` lists lsp under From the hub, running.

## How

- `nodecode add nc://NAME` installs a cell from the hub. With Nodecode running it turns on there, with no restart; otherwise it loads at the next launch.
- In `/cells`, the Hub tab lists the same cells. Space shows where one comes from; a second Space installs it.
- Ask for a part that does not exist yet ("Make a cell that...") and the agent builds it as a cell of its own.
- A cell is a git repository. Push it anywhere to share it. The rest are under <CellsTab />.

Every rule and table: [Cells reference](cells-reference.mdx). How a cell is written: [Cell API](cell-api.mdx).
